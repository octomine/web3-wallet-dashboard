## "Что?" и "Зачем?"

Единое и простое окно в ваш цифровой актив. Вся ключевая информация о вашем кошельке — баланс, токены, транзакции — собрана в одном месте, представлена на понятном языке и красиво визуализирована.

## Быстрый старт

### Скрипты проекта

```bash
# Устанавливка зависимостей
yarn install

# Проверка TypeScript
yarn type-check

# Проверяка линтинга
yarn lint

# Запуск тесты
yarn test

# Запуск dev сервера
yarn dev
```

dev сервер открывается в браузере [http://localhost:3000](http://localhost:3000)
